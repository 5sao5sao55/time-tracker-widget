# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-26

### Added
- Initial release of TimeTracker widget
- Timer functionality with start/stop controls
- Task category selection with predefined options
- Quick detail tags for common subtasks
- Work type classification (Fixed, Ad-hoc, Support)
- Status tracking with multiple options
- Daily task history with delete functionality
- Total daily time calculation
- Excel export with detailed report format
- Summary sheet with task statistics
- Keyboard shortcut (Space) for start/stop
- LocalStorage persistence
- Responsive mobile-friendly design
- Vietnamese localization
- Real-time timer display with tabular numbers
- Work result/output tracking

### Features
- Beautiful gradient UI with Tailwind-inspired design
- Scrollable history with time range display
- Clear visual feedback (running/idle/paused states)
- Automatic date display in Vietnamese format
- Decimal hour conversion for Excel reporting
- Employee information prefilled in reports
- Monthly summary statistics
